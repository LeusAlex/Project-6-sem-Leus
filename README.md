# Генератор управляющих программ для ЧПУ (GRBL)

Курсовой проект. Сайт формирует G-код для фрезерного станка с контроллером GRBL
по трём видам обработки: фрезерование плоскости, круглое отверстие, резьба.

## Технологии

- Фронтенд: чистый HTML + CSS + JavaScript, без фреймворков
- Бэкенд: Node.js + Express (заглушка, данные в JSON-файлах)

## Запуск

1. Установить Node.js (18+)
2. В папке `backend` выполнить:

   npm install
   npm start

3. Открыть http://localhost:3000

## Как пользоваться

1. Выбрать геометрию (плоскость / отверстие / резьба)
2. Ввести геометрические параметры и параметры фрезерования
3. Нажать «Сформировать G-код»
4. Посмотреть код и траекторию, скачать файл .txt
5. Залогиниться и сохранить программу в личный кабинет

## Эндпоинты API

| Метод  | Адрес                | Назначение                    |
|--------|----------------------|-------------------------------|
| POST   | /api/register        | регистрация                   |
| POST   | /api/login           | вход                          |
| GET    | /api/me              | текущий пользователь          |
| GET    | /api/programs        | список сохранённых программ   |
| GET    | /api/programs/:id    | одна программа                |
| POST   | /api/programs        | сохранить программу           |
| DELETE | /api/programs/:id    | удалить программу             |

## Ограничения заглушки

- токен не подписан (просто base64), без срока жизни
- пароль хешируется md5 — небезопасно, только для учебного проекта
- данные хранятся в JSON-файлах, без транзакций
